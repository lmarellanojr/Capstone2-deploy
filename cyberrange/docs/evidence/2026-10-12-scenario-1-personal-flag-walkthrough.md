# Scenario 1: Submit your personal capture flag

For Task 5, use the normal Kali shell and read your lab's flag file:

```sh
cat /opt/cyberrange/flags/scenario1.txt
```

Submit the printed `FLAG{...}` token in Task 5. Your Kali username (for example,
`student` or `tomcat`) is not the flag. Each student receives a different token.

If the file is missing in a lab that was already running when this update was
deployed, end the session and start the lab again so the personal flag is
planted.
